# 💼🖥️ Cyberdeck Portátil em Maleta

Um **cyberdeck portátil** montado dentro de uma maleta, utilizando um **Raspberry Pi 3 rodando Linux**.  
Este repositório documenta todo o processo do projeto — **hardware, software, desafios técnicos** e a **evolução do build**.

---

## ⚙️🔧 Especificações
- 🧠 **Raspberry Pi 3**
- 🖥️ **Monitor 7”** — resolução **1024x600**
- 💾 **HD externo** de **500 GB**
- 🔋 **Power bank** de **30.000 mAh**
- ⌨️ **Teclado**
- 🖱️ **Touchpad**
- 🌐 **entrada para cabo de rede**
- 🔊 **entrada para fone de ouvido**
